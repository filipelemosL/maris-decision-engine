🚀 OPÇÃO 1: RODAR COM PM2 (Recomendado)
════════════════════════════════════════════════════════════════════════════

# 1. Navegar para o projeto
cd "C:\Users\Filipe\Desktop\MDE-REPO\maris-decision-engine\MDE"

# 2. Ativar venv
.venv\Scripts\Activate.ps1

# 3. Instalar PM2 (global)
npm install pm2 -g

# 4. Iniciar API com PM2
pm2 start api_producao.py --name "mde-api" --interpreter "python"

# 5. Configurar para iniciar no boot
pm2 save
pm2 startup

# ✅ Pronto! A API vai rodar 24/7 e reiniciar se cair

# Comandos úteis:
pm2 list              # Ver status
pm2 logs mde-api      # Ver logs em tempo real
pm2 restart mde-api   # Reiniciar
pm2 stop mde-api      # Parar
pm2 delete mde-api    # Remover

⚛️ CRIAR PROJETO NEXT.JS (Se não tiver)
════════════════════════════════════════════════════════════════════════════

# 1. Criar novo projeto
npx create-next-app@latest mde-frontend --typescript

# 2. Entrar na pasta
cd mde-frontend

# 3. Criar arquivo .env.local na raiz
# Conteúdo:
NEXT_PUBLIC_API_URL=https://sua-url-aqui.com

# 4. Copiar arquivo frontend-integration-complete.ts para src/api/

# 5. Criar uma página pages/dashboard.tsx:
"use client";
import { OperationalDashboard } from "@/api/mde-client";

export default function Dashboard() {
  return (
    <div className="p-8">
      <h1 className="text-3xl font-bold mb-8">Maris Decision Engine</h1>
      <OperationalDashboard locationId={1} />
    </div>
  );
}

# 6. Rodar localmente
npm run dev

# 7. Acessar: http://localhost:3000/dashboard

🆘 TROUBLESHOOTING RÁPIDO
════════════════════════════════════════════════════════════════════════════

❌ "ModuleNotFoundError: No module named 'flask'"
→ Falta ativar o venv: .venv\Scripts\Activate.ps1

❌ "ORA-12170: could not connect to Oracle"
→ Oracle não está rodando. Abrir Services do Windows

❌ "CORS error" no navegador
→ URL da API está errada ou CORS não está ativado

❌ "Connection refused: 127.0.0.1:5000"
→ API não está rodando. Executar "python api_producao.py"

❌ ngrok mostra "Timeout"
→ API pode não estar respondendo. Testar localhost:5000 primeiro
