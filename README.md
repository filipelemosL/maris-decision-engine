# Maris Decision Engine

O **Maris Decision Engine** é um sistema de suporte à decisão operacional para ambientes offshore.

Ele coleta dados oceanometeorológicos (vento, altura de onda, pressão atmosférica, temperatura da superfície do mar e correntes), processa essas informações e transforma dados brutos em recomendações operacionais objetivas.

Na prática, o sistema responde perguntas como:

- É seguro iniciar uma operação agora?
- Existe uma janela segura nas próximas horas?
- Qual a probabilidade de interrupção?
- O risco ambiental está aumentando ou diminuindo?

O objetivo não é apenas visualizar dados, mas gerar inteligência aplicada à operação, reduzindo riscos, melhorando o planejamento e apoiando decisões críticas em plataformas e embarcações.
